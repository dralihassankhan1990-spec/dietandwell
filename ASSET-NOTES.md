# Representative visual assets

Calculator visuals use the existing SVG icon set with small CSS motion, shadows and duotone fills. Reduced-motion preferences disable animation. This approach avoids video downloads for small icons.

Shop placeholders: frontend/public/images/shop-products-atlas-v1.png. Generated using the built-in image-generation tool and the imagegen skill. It is illustrative product photography, not a photograph of actual stock or a product label. The site marks these images as illustrative. Existing uploaded product images always take priority; replace them through admin as actual stock images become available. No catalogue records, names, prices or stock values were changed.

Prompt: product-mockup, single 3×3 photographic nutrition ecommerce contact sheet, nine equal cells, warm ivory background, consistent soft upper-left daylight and subtle shadows, generous margins. Row 1: quinoa, pumpkin seeds, almonds. Row 2: flax seeds, chia seeds, unbranded whey protein canister and scoop. Row 3: rolled oats, blank sage-green nutrition book with apple, generic wholefoods and unbranded pouch. Realistic commercial photography at a consistent elevated angle; no people, logos, claims or text; no objects crossing cells.
